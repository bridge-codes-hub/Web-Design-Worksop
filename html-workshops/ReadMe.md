# HTML Workshops 🛠️

This folder contains my practice files from the freeCodeCamp Web Design course. 

### Description-lists.html**
* A quick practice project focused on semantic HTML structure using description lists.
Key Takeaways:
Semantic Structure: Mastered the use of <dl> (description list), <dt> (the term), and <dd> (the description) to logically group related data.
Accessibility: Used proper list tags instead of generic text formatting, making the content much easier for search engines and screen readers to parse.
Description list are perfect for structuring terms for easy reading. Commonly used in FAQ, Contacts etc It contains the dl, dt and dd elements . With dl serving as the main container for dt and dd) The dd is slightly indented to make it distinct dd.
