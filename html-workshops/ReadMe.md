### Quotation Elements**
Description: Practice using semantic HTML elements to properly format block quotes, short quotes, and accurately cite their original sources for both users and search engines.

Key Takeaways:

<blockquote>: Used for long, multi-line quotes. For better formatting, you can wrap multiple separate <p> (paragraph) tags inside this element.
<cite> (The Tag): A visible HTML element used to wrap the title of a referenced work (like a book, movie, or article). Browsers typically display this text in italics.
cite="..." (The Attribute): Placed inside a tag (like <blockquote cite="URL">) to provide a hidden web link to the source. It is invisible to the reader but important for computers and SEO.
<q>: Used for shorter, inline quotes. The browser automatically adds quotation marks around the text wrapped in this tag.
Em dash: written as &mdash; used to indicate a sudden break in thoughts, it preceded a quote. It is a longer dash the width of the letter M.
